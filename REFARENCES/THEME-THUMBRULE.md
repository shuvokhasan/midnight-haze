name: translucent-glassmorphism-ui
description: Design system and UI implementation guidelines for building modern, translucent, frosted-glass desktop/web applications inspired by macOS visionOS/Sonoma aesthetics.UI Design Skillfile: Translucent Frosted GlassmorphismUse this document as a strict rulebook ("thumbrule") whenever generating, styling, or refactoring UI components for this application. The design language relies on deep translucent dark-mode glassmorphism, vibrant wallpaper bleed-through, high-legibility tabular data, and soft, tactile pill/capsule geometries.1. Core Aesthetic & Spatial ArchitectureLayered Depth over Solid Surfaces: Never use flat, opaque hex backgrounds (#000000, #121212) for primary window containers. Every surface is a semi-transparent lens that refracts the vibrant background canvas beneath it.Window Framing:The main application window is a floating container with generous outer border radius (24px – 28px).Specular Rim Lighting: All primary containers, cards, and floating pills must feature a subtle 1px solid rgba(255, 255, 255, 0.14) border (brighter on top/left edges if using gradient borders) to simulate glass edge thickness.Dual-Pane Split Layout:Left Sidebar: Fixed width (220px – 250px), slightly darker tint (rgba(18, 22, 33, 0.55)) with heavy backdrop blur (backdrop-filter: blur(28px) saturate(140%)), separated from the main content area by a hairline vertical divider (1px solid rgba(255, 255, 255, 0.08)).Main Content Canvas: Lighter, more transparent glass (rgba(28, 33, 48, 0.42)), allowing warm and cool tones from the underlying backdrop to subtly shift across the table rows.2. Thumbrule for ContrastBecause background colors shift dynamically behind the glass, never rely on low-contrast gray text.Primary item titles must remain near pure white (rgba(255, 255, 255, 0.92)).Secondary metadata (file sizes, speeds, peer counts) should use cool-tinted translucent white (rgba(215, 225, 245, 0.62)) rather than neutral gray so it harmonizes with both blue and warm coral/orange background bleeds.3. Typography & Data AlignmentFont Stack: -apple-system, BlinkMacSystemFont, "SF Pro Display", "Inter", system-ui, sans-serif.Sidebar Section Headers:Uppercase, 11px, font-weight: 700, letter-spacing: 0.08em, color --text-section-header.Data Tables & Lists:Primary row titles: 13.5px, font-weight: 450, single-line truncation (text-overflow: ellipsis) unless actively selected/expanded.Tabular Numerals (CRITICAL): All numeric columns (Size, Progress, Seeds, Peers, Speed) MUST use font-variant-numeric: tabular-nums; so digits align vertically down every column.Column alignment:Name & Status: Left-aligned.Size, Seeds, Peers, Speed: Right-aligned or centered within fixed-width columns.Progress: Centered pill badge.4. Component BlueprintsA. Top Header & Floating Control PillsWindow Controls: Traditional macOS traffic-light dots (12px diameter, 8px gap) rendered in muted translucent neutral gray (rgba(255, 255, 255, 0.22)) when unfocused, or standard semantic colors on hover.Search Input:Full capsule (border-radius: 9999px), height 36px, background rgba(255, 255, 255, 0.06), border 1px solid rgba(255, 255, 255, 0.12).Contains leading magnifying glass icon, placeholder text (Filter torrents...), and trailing microphone/clear action icon.Action Cluster:Group related toolbar icons (network, notifications, audio, settings) inside a single shared frosted capsule (border-radius: 9999px) rather than separate boxes.Separate primary user profile avatar into its own standalone circular glass button (36px × 36px).B. Sidebar Navigation ItemsItem Height: 32px – 34px, horizontal padding 12px, border-radius: 9999px (full pill).Active State:Soft translucent white fill (rgba(255, 255, 255, 0.14)), subtle top specular border (1px solid rgba(255, 255, 255, 0.18)), bold white text (font-weight: 500), and crisp white leading icon (15px).Inactive State:Transparent background, muted icon (rgba(255, 255, 255, 0.55)), and secondary text (rgba(255, 255, 255, 0.78)). On hover, transition smoothly (150ms ease) to rgba(255, 255, 255, 0.06).C. Table Header & RowsTable Header Pill:Wrap the table column headers inside a single floating rounded bar (border-radius: 12px, height 34px, background rgba(255, 255, 255, 0.08), border 1px solid rgba(255, 255, 255, 0.12)).Separate column headers with subtle vertical hairlines (1px solid rgba(255, 255, 255, 0.1)).Table Rows:Separated by ultra-thin horizontal hairlines (1px solid rgba(255, 255, 255, 0.06)).Selected / Focused Row: Elevated frosted glass highlight (rgba(255, 255, 255, 0.11)), subtle rounded corners (10px), and full multi-line text expansion if the title overflows.Progress Pill Badge:Compact capsule (height: 20px, min-width: 76px, border-radius: 9999px).Completed (100%): Muted slate-cyan fill (rgba(140, 175, 205, 0.35)) with crisp white 11.5px centered text.Active (<100%): Linear gradient fill showing completion percentage in vibrant cyan (#5AC8FA) over rgba(255, 255, 255, 0.1).D. Bottom Inspector Tabs & Status BarInspector Sub-Navigation:Horizontal tab row anchored at the bottom of the main glass panel.Active Tab: Rounded rectangle pill (border-radius: 8px, padding: 6px 14px), tinted cyan-glass fill (rgba(75, 130, 165, 0.35)), text #70D7FF.Inactive Tabs: Plain text (--text-secondary), hover brightens to --text-primary.External Footer Bar (Outside Main Glass Window):Placed directly over the blurred wallpaper below the main window frame (height: 32px).Displays global telemetry (DHT nodes, quick toggle icons, global upload/download speeds) in high-contrast white/light-blue text with subtle drop-shadow (0 1px 2px rgba(0,0,0,0.4)) for guaranteed readability over any wallpaper.5. Do's & Don'ts Checklist for Code GenerationDO apply backdrop-filter: blur(24px) saturate(135%) (with -webkit-backdrop-filter) on all primary glass containers.DO use rgba() borders on every floating pill, header bar, and modal to prevent glass elements from visually bleeding into each other.DO enforce tabular-nums on all file sizes, percentages, peer counts, and transfer speeds.DON'T use heavy drop shadows (box-shadow: 0 20px 50px rgba(0,0,0,0.8)) on inner elements—inner elevation is communicated through surface brightness and border opacity, not dark shadows. Only the outer application window gets a deep ambient shadow.DON'T use sharp 0px–4px corners. Every interactive surface must follow the concentric rounding hierarchy: Outer Window (26px) $\rightarrow$ Inner Cards/Headers (12px) $\rightarrow$ Tabs (8px) $\rightarrow$ Pills/Badges (9999px).
