# Project Snapshot: qbt-theme (Glass / Midnight Haze)

Snapshot date: 2026-11-20. Read this file first to get full context before you change the project.

## 1. What this project is

A custom UI theme for the **qBittorrent desktop app** (written and tested against qBittorrent **5.2.3** on **macOS**).
The theme copies a dark "frosted glass" (glassmorphism) look, in the style of macOS Sonoma / visionOS.

- Internal name: **Glass**. The build writes `dist/glass.qbtheme`.
- Published name: **Midnight Haze**. `dist/midnight-haze.qbtheme` is a renamed copy of the build output
  (latest commit `e9964c6 Update: Theme Name` renamed `glass-2.qbtheme` to `midnight-haze.qbtheme`).
  At snapshot time both files are byte-identical (same MD5). The build script does **not** write
  `midnight-haze.qbtheme`; copy it by hand after a build, or change `OUT` in `tools/build.py`.

A `.qbtheme` file is a Qt binary resource bundle (made by `rcc --binary`). qBittorrent mounts it at the
resource path `:/uitheme/`. It may hold:

- `stylesheet.qss` — Qt Style Sheet applied to the whole app.
- `config.json` — colour IDs (QPalette roles + qBittorrent-specific colours).
- `icons/<icon-id>.svg` — replacements for qBittorrent's built-in icons.
- Any other files the QSS references with `url(:/uitheme/...)`.

There is no application code. The project is: one QSS file, one JSON file, generated assets, and Python
generator / build / preview scripts.

## 3. Build, preview, install

```sh
python3 -m venv .venv
.venv/bin/pip install PySide6 Pillow
.venv/bin/python tools/build.py              # writes dist/glass.qbtheme
.venv/bin/python tools/build.py --background # also regenerates src/background.png
.venv/bin/python tools/preview.py            # writes build/preview-*.png (needs a built dist/glass.qbtheme)
.venv/bin/python tools/preview.py --queueing # preview with the 4 queue buttons visible
```

`tools/build.py` steps, in order:

1. `make_icons.main()` — rewrites every SVG in `src/icons/` and `src/ui/`.
2. `make_capsule.main()` — rewrites `src/ui/search-cap.png`, `progress-chunk.png`, `hover-disc.png`, `pressed-disc.png` (+ `@2x` variants).
3. `make_background.main()` — only with `--background` or when `src/background.png` is missing.
4. `validate_config()` — exits if `config.json` (`colors` or `colors.dark`) has an ID not in `color_ids.txt`.
5. `report_icons()` — exits if an SVG in `src/icons/` has no matching ID in `icon_ids.txt`;
   prints a note for IDs with no SVG (except `KEEP_STOCK` tray icons).
6. Writes `build/glass.qrc` with every file under `src/` (alias = path relative to `src/`).
7. Runs `pyside6-rcc --binary -o dist/glass.qbtheme build/glass.qrc`.

Install in qBittorrent: **Preferences > Behavior > Interface > Use custom UI Theme**, pick the `.qbtheme`,
restart the app. For fast iteration pick `src/config.json` instead: qBittorrent then loads the `src/` folder
directly and edits need only an app restart, no rebuild.

Verification: there are no automated tests. Checks are (1) the build validation, (2) `preview.py`
screenshots, (3) the real qBittorrent app, which is the final check.

## 4. Key rule: generated vs hand-written files

| File | Edit directly? | Source of truth |
| --- | --- | --- |
| `src/stylesheet.qss` | Yes | itself |
| `src/config.json` | Yes | itself (IDs must exist in `tools/color_ids.txt`) |
| `src/icons/*.svg`, `src/ui/*.svg` | **No** | `ICON_DEFS` / `UI_DEFS` in `tools/make_icons.py` |
| `src/ui/*.png` (search-cap, progress-chunk, hover-disc, pressed-disc) | **No** | `tools/make_capsule.py` |
| `src/background.png` | **No** | `tools/make_background.py` (rebuild with `--background`) |
| `dist/*.qbtheme`, `build/*` | **No** | output of `tools/build.py` / `tools/preview.py` |

Every build overwrites the generated SVGs and capsule PNGs. A hand edit to them is lost.

## 5. Design system (from REFARENCES/THEME-THUMBRULE.md, as applied)

QSS has no variables. The token values are listed in the header comment of `src/stylesheet.qss` and repeated
literally in each rule. Keep the header comment in sync if you change a token.

Tokens:

- Text: primary `rgba(255,255,255,0.94)`, secondary `rgba(225,232,245,0.65)`, muted `rgba(190,202,224,0.45)`.
- Surfaces: `rgba(255,255,255,0.07)`, hover `0.11`, active `0.16`.
- Borders: outer `rgba(255,255,255,0.18)`, subtle `rgba(255,255,255,0.08)`.
- Accent cyan `#5AC8FA`; active tab text `#70D7FF`; popup solid fill `#1a2036`; dialog fill `#24244c`.
- Status colours: seeding/info `#64D2FF`, downloading `#30D158`, warning `#FFD60A`, error `#FF453A`.
- Radius hierarchy: cards/headers 12px, tabs/buttons 8px, pills = half the height.

Icons (`tools/make_icons.py`): 24x24 grid, monochrome line icons, 1.8px rounded stroke. Toolbar icons
(`TOOLBAR_ICONS`) use a 2.4px stroke. Icon colours: white `#E6ECF8`, muted `#8E9AB8`, cyan `#64D2FF`,
green `#30D158`, yellow `#FFD60A`, red `#FF453A`. Tray icons (`KEEP_STOCK`) stay stock on purpose so the
menu bar keeps the qBittorrent mark.

Background (`tools/make_background.py`): 1280x800 navy base `(13,16,38)` with 7 colour blobs (blue, violet,
coral, magenta, cyan, teal, warm accent), Gaussian blur 120, then a dark veil for text contrast. It stands
in for the desktop wallpaper because qBittorrent cannot blur what is behind its window.

### Toolbar capsule trick (fragile, read before editing)

qBittorrent fixes the toolbar item order: action buttons, flexible gap, search/filter field, lock button.
QSS cannot wrap a group of items in a box, so two "capsules" are assembled from the items themselves:

- Left capsule: every tool button paints the same fill `rgba(30,30,36,0.78)`; toolbar `spacing: 0`.
  The round ends are matched by the English button text (`Open` = left end, `Preferences` = right end).
  In other UI languages those ends are square.
- Spacer widgets between button groups match `QToolBar > QWidget[minimumWidth="16"]` and get the same fill.
- Right capsule: `QToolBar > QWidget` (the filter container) shows `ui/search-cap.png` anchored right.
  That image paints the right capsule's left end + body and the right part of the inner search pill.
  `QToolBar > QWidget > QLineEdit` paints the left part of the search pill (`#14151b`, border `#3a3c46`).
- Pixel widths in `tools/make_capsule.py` (`WIDTH=395`, `HEIGHT=34`, layout: 6 margin, 100 drop-down,
  8 gap, 65 label, 10 gap, 192 line edit, 14 to capsule end) **must match** the widths fixed in the
  `QToolBar > QWidget > ...` QSS rules. Change both together.
- Qt insets toolbar items by `(border-left + padding-left) + margin-top` on every side, so border and
  padding stay 0 and margin stays uniform (`margin: 6px`).

## 7. config.json

Only a `colors` section (no `colors.dark`). Groups:

- `Palette.*` — QPalette roles (dark navy window `#141a2e`, base `#171d33`, highlight `#3d6f96`, link `#5ac8fa`, disabled text `#7c869e`).
- `Log.*` — execution log colours.
- `RSS.ReadArticle` / `RSS.UnreadArticle`.
- `TransferList.*` — text colour per torrent state (downloading green, uploading cyan, queued yellow,
  checking/moving cyan, stopped muted/lavender, error/missing red).
- `PiecesBar.*` and `ProgressBar`.

Full list of valid IDs: `tools/color_ids.txt`.

## 8. Known limits of a .qbtheme (do not try to implement)

From README, verified by the author:

- No real blur or wallpaper bleed-through; gradient is baked into the window.
- No layout changes (search pill in title bar, extra header buttons, footer outside window).
- Cannot reorder toolbar items.
- Progress fill cannot be clipped to the track; fills narrower than 14px have overlapping round ends.
- Tooltip windows stay square (only the border line is rounded).
- Native macOS title bar and window corner radius cannot change.
- No rounded corners on selected table rows; no multi-line expansion of selected rows.
- Completed and in-progress bars cannot have different fills (QSS cannot select on value).
- No QSS font on progress bars (breaks label position in the transfer list).
- Tray icons stay stock.

## 9. Conventions and gotchas for agents

- Run tools with `.venv/bin/python` from the repo root. Scripts resolve paths from their own location.
- After any change to `src/` or `tools/`, run `tools/build.py`, then `tools/preview.py`, and look at
  `build/preview-*.png`.
- Adding an icon: add an entry to `ICON_DEFS` in `tools/make_icons.py`; the name must be in
  `tools/icon_ids.txt` or the build fails.
- Adding a colour: the key must be in `tools/color_ids.txt` or the build fails.
- QSS resource URLs use the `:/uitheme/` prefix (e.g. `url(:/uitheme/ui/check.svg)`).
- `preview.py` mirrors qBittorrent widget classes and paints table progress bars like qBittorrent's
  `ProgressBarPainter`. It is an approximation, not the real app.
- No `.gitignore`: `tools/__pycache__/` is committed and `.venv/` is untracked. Do not commit `.venv/`.
- Git: branch `main`; history is 2 commits (`350f297 Initial commit`, `e9964c6 Update: Theme Name`).
